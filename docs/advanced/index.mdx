# Отдельные темы

Здесь живут страницы-углубления: темы, которые не помещаются в основные главы, но регулярно всплывают на чемпионате и в реальной работе. Каждая — уровня «углубление» на карте знаний: проходить их можно в любом порядке и в любой момент, базовый маршрут от них не зависит.

## Предложить свою тему

Раздел открыт для статей от сообщества. Если у тебя есть тема, которая «не влезла» в главы — сетевые утилиты, tmux, Docker-хитрости, что угодно по делу:

1. Попроси наставника выдать тебе роль автора — по логину на GitHub.
2. Открой [редактор](/edit) и нажми «+ Новая страница». Ни программы, ни git для этого не нужны: весь порядок разобран в главе [«Как добавить страницу на платформу»](/docs/advanced/kak-dobavit-stranicu).
3. Наставник посмотрит и подскажет правки. Факты проверяем по официальной документации — ссылки на неё обязательны.
