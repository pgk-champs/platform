# Отдельные темы

Здесь живут темы, которые не помещаются в основные главы, но регулярно всплывают на чемпионате и в реальной работе. Порядок не важен: базовый маршрут от этого раздела не зависит. Рядом с главами-углублениями лежат простые страницы — памятки и разборы, у них нет ни экзамена, ни прогресса.

## Предложить свою тему

Раздел открыт для статей от сообщества. Если у тебя есть тема, которая «не влезла» в главы — сетевые утилиты, tmux, Docker-хитрости, что угодно по делу:

1. Попроси наставника выдать тебе роль автора — по логину на GitHub.
2. Открой [редактор](/edit) и нажми «+ Новая страница». Ни программы, ни git для этого не нужны: весь порядок разобран в [«Как добавить материал»](/docs/advanced/kak-dobavit-stranicu).
3. Наставник посмотрит и подскажет правки. Факты проверяем по официальной документации — ссылки на неё обязательны.
