# Как добавить страницу на платформу

Страницу можно завести прямо на сайте — ни программы, ни git для этого не нужны.
Эта инструкция целиком помещается на один экран, и так и задумано.

## Что нужно один раз

1. Войти в [личный кабинет](/account) через GitHub.
2. Попросить наставника выдать вам **роль автора** — он делает это у себя в разделе
   «Наставнику», по вашему логину на GitHub.

После этого в кабинете появится кнопка **«Править страницы»**, а по адресу
[/edit](/edit) откроется редактор.

<Hint type="tip">
Если кнопки нет — значит роль ещё не выдали. Сама страница `/edit` при этом честно
скажет, чего не хватает, и ничего не сломается.
</Hint>

## Два вида материалов

| | Простая страница | Глава |
| --- | --- | --- |
| Что это | памятка, объявление, разбор задания | полноценный учебный материал |
| Что обязательно | только текст | обложка, 2–5 схем, экзамен, 4–5 видео |
| Сколько занимает | минуты | несколько часов |

Выбирайте простую страницу, если сомневаетесь. Превратить её в главу потом можно —
достаточно убрать строку `kind: 'page'` и дописать недостающее.

## Как добавить

1. Откройте [/edit](/edit) и нажмите **«+ Новая страница»**.
2. Выберите раздел, впишите заголовок и вид материала.
3. Нажмите **«Создать заготовку»** — адрес и номер подставятся сами, из заголовка.
4. Напишите текст. Кнопки над полем вставляют подсказку, раздел, «проверь себя» и код.
5. Нажмите **«Создать»**.

Через несколько минут страница появится на сайте: сохранение отправляет её в
репозиторий, а дальше платформа пересобирается сама.

<Hint type="important">
Кнопка сохранения не нажимается, пока над полем горит список замечаний. Это не
придирки: ровно те же вещи проверяет сборка, и без них страница просто не соберётся.
Исправьте замечания — кнопка станет активной.
</Hint>

## Как поправить существующую

Откройте [/edit](/edit), найдите страницу в списке слева (там есть поиск),
измените текст и нажмите **«Сохранить»**.

Если ту же страницу успел изменить кто-то ещё, сохранение не пройдёт и редактор
об этом скажет — откройте её заново и внесите правку ещё раз. Так чужая работа не
затирается молча.

## Как добавить целый раздел

Разделы (треки) описаны одним файлом `src/data/tracks.json`. Чтобы появился новый —
например «Веб» или «1С» — в него добавляется запись:

```json
{
  "dir": "web",
  "label": "Веб",
  "audience": "веб",
  "position": 5,
  "art": "grep-regex",
  "blurb": "Короткое описание раздела."
}
```

После этого раздел появится и в редакторе, и в меню сайта. Это единственное место,
где треки перечислены: подписи, порядок и допустимые значения `audience` берутся
отсюда же.

<Hint type="fact">
Номер главы — это префикс имени файла (`07-composition.mdx` → глава 07). Чтобы
перенумеровать материалы, достаточно переименовать файлы: нигде больше номер не
дублируется и разойтись не может.
</Hint>

## Что делать, если что-то пошло не так

- **«Нет доступа»** — роль автора не выдана. Попросите наставника.
- **«На сервере не настроен ключ доступа»** — это к администратору платформы: без
  ключа сохранение не работает, страницы только читаются.
- **«Страницу успели изменить»** — откройте её заново, ваш текст не потерян: скопируйте
  его перед повторным открытием.
- **Страница не появилась через десять минут** — скорее всего, сборка упала.
  Загляните во вкладку Actions репозитория: там будет видно, на чём именно.
