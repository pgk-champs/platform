# Отдельные темы

Здесь живут страницы-углубления: темы, которые не помещаются в основные главы, но регулярно всплывают на чемпионате и в реальной работе. Каждая — уровня «углубление» на карте знаний: проходить их можно в любом порядке и в любой момент, базовый маршрут от них не зависит.

Сейчас в разделе:

- **Регулярные выражения для grep** — как искать в файлах не точный текст, а шаблон: классы символов, якоря, квантификаторы.
- **SSH-ключи глубоко** — пара ключей изнутри, агент, файл `~/.ssh/config` и несколько ключей на одной машине.
- **Rebase мастерски** — когда переписывать историю можно, когда нельзя, и что делает интерактивный режим.

## Предложить свою тему

Раздел открыт для статей от сообщества. Если у тебя есть тема, которая «не влезла» в главы — сетевые утилиты, tmux, Docker-хитрости, что угодно по делу:

1. Возьми за образец любую страницу этого раздела: шапка с `audience`/`level`/`order`, разделы с самопроверками, шпаргалка и «Куда дальше» с проверенными ссылками.
2. Добавь файл в `docs/advanced/` и открой pull request — как это делается, разбирается в главе про push и PR.
3. Наставник посмотрит, подскажет правки и вольёт. Факты проверяем по официальной документации — ссылки на неё обязательны.
