# Linux и терминал

## Зачем это нужно

На чемпионате «Профессионалы» рабочая машина — не Windows, а Ubuntu. Это самый популярный дистрибутив Linux — операционной системы, на которой крутится почти весь интернет: серверы, облака, суперкомпьютеры, и даже Android внутри — это ядро Linux. Организаторы выбирают Linux не из вредности: он бесплатный, одинаковый у всех участников и в нём удобно автоматизировать проверку заданий. Так что чем раньше Ubuntu станет для тебя привычной, тем меньше сюрпризов будет на площадке.

Главный инструмент в Linux — терминал (terminal): окно, в котором ты общаешься с компьютером текстом. Выглядит как чёрный экран из фильмов про хакеров, но на деле это просто диалог: ты пишешь команду (command), нажимаешь Enter — компьютер отвечает. Никакой магии и ничего страшного: худшее, что случится у новичка, — компьютер вежливо скажет `command not found`. Зато многие вещи в терминале делаются в разы быстрее, чем мышкой, а некоторые — только в нём.

## Разбираем команду

Любая команда собирается из одних и тех же деталей: *что делать*, *как именно* и *над чем*. Наведи курсор на каждую часть — появится подсказка.

]} />

Уточнения вроде `-l` и `-a` называются флагами (flag): они начинаются с дефиса и меняют поведение команды.

Путь (path) — это адрес файла или папки. `/home/student` читается так: в корне системы есть каталог `home`, в нём — `student`. Это домашний каталог пользователя student — в терминале у него есть короткое имя `~` (тильда).

## Базовые команды

Папки в Linux называют каталогами (directory), но это одно и то же. Вот набор, которого хватает на 90% работы:

| Команда | Что делает | Пример |
|---|---|---|
| `pwd` | показать, где я сейчас нахожусь | `pwd` |
| `ls` | показать содержимое каталога | `ls -la` |
| `cd` | перейти в другой каталог | `cd project` |
| `mkdir` | создать каталог | `mkdir project` |
| `touch` | создать пустой файл (file) | `touch notes.txt` |
| `cp` | скопировать | `cp notes.txt copy.txt` |
| `mv` | переместить или переименовать | `mv copy.txt docs/` |
| `rm` | удалить | `rm copy.txt` |

Пара приёмов, без которых в терминале тяжело: `cd ..` поднимает на уровень вверх, `cd ~` возвращает в домашний каталог, а стрелка ↑ подставляет предыдущую команду — не перепечатывай одно и то же. Если забыл, как работает команда, допиши `--help`: например, `ls --help`.

**Осторожно с `rm`.** В терминале нет корзины: то, что удалила `rm`, восстановить нельзя. Никакого «вы уверены?» тоже не будет — команда молча сделает ровно то, что ты написал. Поэтому перед `rm` дважды проверь, что стоит после неё, и никогда не запускай команды с `rm`, скопированные из интернета, если не понимаешь каждую их часть.

## Практикум: собери проект руками

Открой терминал в Ubuntu (Ctrl+Alt+T) и создай структуру для учебного проекта — только командами, без мышки:

```bash
cd ~
mkdir project
cd project
mkdir src
mkdir docs
touch README.md
touch src/main.py
ls -la
```

Последняя команда покажет, что внутри `project` появились `src`, `docs` и `README.md`. Теперь потренируй `cp`, `mv` и `rm`:

```bash
cp README.md docs/copy.md
mv docs/copy.md docs/notes.md
rm docs/notes.md
```

Скопировали файл в `docs`, переименовали его, удалили. Проверь результат через `ls docs` — каталог снова пуст. Кстати, несколько команд можно склеить в одну строку через `&&`: вторая выполнится, только если первая прошла без ошибок.

<details>
<summary>Углубиться</summary>

**Терминал и оболочка — не одно и то же.** Терминал — это только окно. Внутри него работает оболочка (shell) — программа, которая читает твои команды, находит нужные программы и запускает их. В Ubuntu по умолчанию это bash. Поэтому «выучить терминал» на самом деле значит «выучить язык оболочки».

**Справка всегда под рукой.** У каждой команды есть встроенное руководство — man-страница (от manual): набери `man ls` и получишь полное описание всех флагов. Листать — стрелками, выйти — клавишей `q`. Это первоисточник: любой урок в интернете пересказывает именно man-страницы.

**Скрытые файлы.** Файл, чьё имя начинается с точки (например `.bashrc`), Linux считает скрытым — обычный `ls` его не показывает. Так прячут настройки программ, чтобы не мешались. Флаг `-a` из нашей команды `ls -la` показывает и их.

## Челлендж ⭐

Для нового проекта нужна вот такая вложенная структура:

```
app/
└── assets/
    └── images/
```

Создай её **одной командой**. Обычный вызов `mkdir app/assets/images` откажется работать — попробуй и прочитай, что он ответит. Способ есть, и он прячется в справке самой команды: `mkdir --help` или `man mkdir`. Проверь результат через `ls app/assets`.

<details>
<summary>Решение (сначала попробуй сам)</summary>

```bash
mkdir -p app/assets/images
```

Флаг `-p` (parents) говорит mkdir: создай и все промежуточные каталоги по пути, если их ещё нет. Без него команда требует, чтобы `app` и `app/assets` уже существовали.

</details>

## Что должен уметь

- Объяснять, почему на чемпионате используется Ubuntu и что такое Linux, своими словами.
- Разбирать любую команду на три части: команда, флаги, аргумент — на примере `ls -la /home/student`.
- Перемещаться по файловой системе с помощью `pwd`, `ls`, `cd`, включая `cd ..` и `cd ~`.
- Создавать структуру каталогов и файлов командами `mkdir` и `touch`, копировать и переименовывать через `cp` и `mv`.
- Формулировать, чем опасна `rm`, и проверять команду перед запуском.
