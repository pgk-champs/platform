# Android Studio: знакомство с IDE

## Зачем это нужно

Программа — это текст, а текст можно набрать хоть в блокноте. Но блокнот не знает, что ты пишешь код: он не подскажет, что в слове опечатка, не покажет, где не хватает скобки, и уж точно не соберёт из твоего текста работающее приложение. Для этого существует интегрированная среда разработки (IDE, Integrated Development Environment) — программа, в которой под одной крышей живут редактор кода, сборщик, запуск приложения и поиск ошибок. Разница как между отвёрткой и оборудованной мастерской: закрутить один шуруп можно и отвёрткой, но собирать шкаф удобнее там, где всё под рукой.

Для Android официальная IDE — Android Studio от Google. В ней работают и профессиональные разработчики, и участники чемпионата «Профессионалы»: на площадке тебя будет ждать именно она. В этой главе поставим её на Ubuntu, разберёмся, что где находится в окне, создадим первый проект и запустим его на виртуальном телефоне — не выходя из-за компьютера.

## Чем IDE лучше блокнота

IDE понимает язык, на котором ты пишешь. Пока ты набираешь код, она:

- **подчёркивает ошибки** сразу, а не после запуска — как проверка орфографии, только для Kotlin;
- **дописывает за тебя**: набрал три буквы — получил список подходящих продолжений;
- **знает весь проект (project)** — совокупность файлов приложения: код, картинки, настройки. Переименуешь функцию в одном файле — IDE поправит её во всех остальных.

1. Скачай архив для Linux (файл вида `android-studio-...-linux.tar.gz`).
2. Распакуй его, например в домашнюю папку, и запусти скрипт `studio.sh` из папки `bin`:

```bash
tar -xzf android-studio-*-linux.tar.gz
./android-studio/bin/studio.sh
```

3. При первом запуске откроется мастер настройки. Соглашайся с вариантами по умолчанию — он докачает Android SDK (набор инструментов для сборки под Android). Это несколько гигабайт, так что понадобятся интернет и терпение.

## Окно Android Studio: что где

Когда откроешь проект, экран будет выглядеть пугающе — панелей много. На старте важны четыре:

- **Редактор** (центр) — здесь ты пишешь код. Главное место в IDE.
- **Project** (слева) — дерево файлов проекта. Как проводник, только для кода.
- **Terminal** (внизу) — обычный терминал Linux, встроенный прямо в IDE, чтобы не переключать окна.
- **Logcat** (внизу) — журнал запущенного приложения: сюда оно пишет, что с ним происходит, и сюда же падают сообщения об ошибках. Первое место, куда смотрят, когда «ничего не работает».

Остальные панели пока можно не трогать: понадобятся — узнаешь о них по ходу дела.

## Первый проект и первый запуск

**Создаём проект.** На стартовом экране нажми **New Project** и выбери шаблон **Empty Activity** — это заготовка приложения с одним экраном. Дай проекту имя (латиницей, без пробелов) и жми **Finish**.

**Ждём синхронизацию.** Дальше внизу побегут полоски прогресса — это работает Gradle, система сборки. Она читает описание проекта, докачивает нужные библиотеки и готовит всё к сборке. Этот процесс называется синхронизацией (sync). Первая занимает несколько минут — не пугайся и ничего не нажимай, дождись надписи об успехе.

**Создаём виртуальный телефон.** Настоящий Android-телефон для запуска не обязателен: в Android Studio встроен эмулятор (emulator) — виртуальный смартфон, который открывается в окне на твоём компьютере. Открой **Device Manager** (иконка телефона справа), нажми **Create Virtual Device**, выбери любой Pixel и системный образ, который IDE предложит скачать.

**Запускаем.** Жми зелёный треугольник ▶ на верхней панели (или **Shift+F10**). IDE соберёт проект, запустит эмулятор и установит туда приложение. Через минуту-другую на виртуальном экране появится надпись «Hello Android!». Поздравляю — ты только что собрал и запустил своё первое Android-приложение.

Эта надпись берётся из файла `MainActivity.kt` — найди его в панели Project. Внутри есть строка, которую стоит разобрать по составу (наведи курсор на каждую часть):

## Топ-5 горячих клавиш

Горячая клавиша (shortcut) — комбинация, которая делает то же, что три клика мышью, но мгновенно. Эти пять окупаются с первого дня:

| Комбинация | Что делает |
|---|---|
| **Ctrl+Space** | Автодополнение: показать варианты продолжения кода |
| **Shift+Shift** | Искать всё и везде: файлы, функции, настройки |
| **Ctrl+/** | Закомментировать/раскомментировать строку |
| **Alt+Enter** | Быстрое исправление: IDE сама предлагает, как починить подчёркнутое |
| **Ctrl+Alt+L** | Отформатировать код: расставить отступы красиво |

Не заучивай список — повесь на него глаза и пробуй по одной в день. Через неделю рука будет тянуться сама.

<details>
<summary>Углубиться</summary>

**Что на самом деле делает Gradle.** «Собрать приложение» — это не один шаг: нужно скомпилировать Kotlin-код, упаковать картинки и настройки, скачать библиотеки, о которых просит проект, подписать итоговый файл и сложить всё в один APK — установочный пакет Android. Gradle делает это по описанию из файлов `build.gradle.kts` в корне проекта: там перечислено, из чего приложение состоит и какие библиотеки ему нужны. Поэтому когда меняются эти файлы, IDE просит повторить sync — она должна перечитать «рецепт».

**Как устроен эмулятор.** Эмулятор — это полноценный Android, запущенный внутри виртуальной машины на твоём компьютере. Чтобы он не тормозил, на Ubuntu используется аппаратное ускорение через KVM — модуль ядра Linux для виртуализации. Если эмулятор еле шевелится, первым делом проверяют, включена ли виртуализация в BIOS и доступен ли KVM.

**Все горячие клавиши разом.** Пяти комбинаций из главы хватит на старт, но у Android Studio их сотни, и под Linux, Windows и macOS они местами различаются — сверяйся с официальной таблицей.

## Челлендж ⭐

Сделай так, чтобы твоё приложение здоровалось с тобой по имени.

1. Создай проект из шаблона Empty Activity (если ещё не создал) и запусти его на эмуляторе — убедись, что видишь «Hello Android!».
2. Найди в проекте место, где живёт этот текст, и замени его на приветствие с твоим именем.
3. Запусти приложение снова и добейся, чтобы новый текст появился на экране эмулятора.

Подсказка: разбор строки «по составу» из середины главы показывает ровно то место, которое нужно менять. А **Shift+Shift** поможет найти нужный файл быстрее, чем блуждание по дереву проекта.

<details>
<summary>Решение (сначала попробуй сам)</summary>

Текст живёт в файле `MainActivity.kt` (панель Project → app → java/kotlin → папка с именем твоего пакета). Внутри найди вызов с `"Hello Android!"` — чаще всего строка передаётся в функцию `Greeting`, а та рисует её через `Text(...)`. Замени строку в кавычках:

```kotlin
Greeting(name = "Олег")
```

или, если правишь сам `Text`:

```kotlin
Text(text = "Привет, Олег!")
```

Нажми ▶ (Shift+F10) — IDE пересоберёт проект и обновит приложение на эмуляторе. Если текст не поменялся, проверь Logcat: возможно, сборка упала из-за потерянной кавычки или скобки.

</details>

## Что должен уметь

- Объяснять своими словами, что такое среда разработки (IDE) и чем она отличается от простого текстового редактора.
- Показывать в окне Android Studio редактор, панель Project, Terminal и Logcat и говорить, зачем каждая нужна.
- Создавать проект из шаблона Empty Activity и понимать, что происходит во время синхронизации (sync) Gradle.
- Запускать приложение на эмуляторе (emulator) и находить результат изменения кода на его экране.
- Пользоваться минимум тремя горячими клавишами (shortcut) из топ-5, не подглядывая в таблицу.
