# Переменные и типы

## Зачем это нужно

Любая программа что-то запоминает: очки игрока, имя пользователя, список покупок. Место, где хранится такое значение, называется переменной (variable) — это просто имя, за которым компьютер закрепляет ячейку памяти. Без переменных пришлось бы писать число или строку заново в каждом месте кода, где они нужны, и при любом изменении править всё вручную. С переменной достаточно один раз задать значение и дальше ссылаться на него по имени — а если значение поменяется, весь код, который на него смотрит, автоматически получит новое.

В Kotlin у каждой переменной есть тип (type) — метка, которая говорит компилятору, какого рода данные внутри: целое число, текст, список чисел. Тип определяет, какие операции с переменной вообще имеют смысл: строки можно склеивать, числа — складывать, а вот сложить число со строкой напрямую не выйдет. Дальше в этой главе разберём, как Kotlin объявляет переменные, откуда берётся тип и почему его не всегда нужно писать руками.

## Как это работает

**val и var.** `val` (от value) объявляет неизменяемую (immutable) переменную: значение задаётся один раз и переприсвоить его нельзя — попытка сделать это не пройдёт компиляцию. `var` (от variable) объявляет переменную, которую можно менять сколько угодно раз. Хорошее правило для новичка: по умолчанию бери `val`, и переключайся на `var` только тогда, когда точно знаешь, что значение будет меняться, — так меньше шанс случайно испортить данные, на которые полагается остальной код.

**Тип и вывод типов.** В примере выше `x` помечен как `Int`. Но это необязательно: если справа от `=` уже стоит выражение, по которому понятно, что получится число, Kotlin сам определит тип — это называется выводом типов (type inference). Явную аннотацию обычно оставляют, когда без неё код становится непонятным, или когда типа, который нужен, из правой части не видно.

**Списки и обработка данных.** `listOf(1, 2)` создаёт список (list, `List<Int>`) — упорядоченный набор элементов одного типа. `.map { it * 2 }` — это вызов функции (function) `map`, которой передаётся лямбда-выражение (lambda): маленький кусок кода без имени, который здесь удваивает каждый элемент. `it` — сокращение для единственного параметра лямбды, писать его явно не обязательно. Наконец `.sum()` — терминальная операция: она не возвращает список, а сворачивает его в одно число.

Ниже — рабочий пример. Нажми **Run**, чтобы выполнить его прямо в браузере.

<KotlinPlay code={`fun main() {
    val name: String = "Соня"
    var score = 0
    score += 15
    score += 27
    println("$name набрала $score очков")
}`} />

Здесь `name` — `val`: имя участника не меняется по ходу дела. `score` — `var`: к нему дважды прибавляют число, поэтому неизменяемая переменная не подошла бы. Обрати внимание, что у `score` нет аннотации типа — Kotlin вывел `Int` сам, по значению `0`.

Лямбду необязательно писать через `it`. Когда параметров несколько или так понятнее, параметр называют явно и отделяют стрелкой (`->`):

<KotlinPlay code={`fun main() {
    val calculateBonus: (Int) -> Int = { score -> score * 2 + 10 }
    println(calculateBonus(15))
}`} />

<details>
<summary>Углубиться</summary>

**val и var под капотом.** Любое свойство в Kotlin — не просто ячейка памяти, а пара функций-аксессоров: геттер (getter), который читает значение, и, только для `var`, сеттер (setter), который его меняет. Компилятор генерирует их сам, а также backing field — скрытое поле, где значение фактически хранится. Поэтому `val` — это не "переменная без сеттера" как синтаксический трюк, а тип, у которого сеттера действительно нет: изменить значение снаружи буквально нечем.

**Вывод типов.** Компилятор смотрит на выражение справа от `=` и решает, какой тип нужен переменной слева, ещё во время компиляции — то есть до запуска программы. Это не динамическая типизация: тип фиксируется раз и навсегда, просто программисту не обязательно писать его руками каждый раз.

## Челлендж ⭐

Спортивная команда пробежала за неделю пять тренировок: `listOf(3, 5, 4, 6, 2)` километров. Организаторам чемпионата нужна общая дистанция в метрах, а не в километрах.

Напиши **одно выражение** — по образцу `listOf(...).map { ... }.sum()` из начала главы, — которое переводит каждое значение из километров в метры и сразу суммирует результат. Проверь себя, запустив код ниже.

<KotlinPlay code={`fun main() {
    val distancesKm = listOf(3, 5, 4, 6, 2)
    // допиши выражение: список километров -> сумма метров
    val totalMeters = distancesKm.map { it * 1000 }.sum()
    println("Всего пробежали: $totalMeters м")
}`} />

## Что должен уметь

- Объяснять разницу между `val` и `var` и обосновывать, какой из них выбрать в конкретной ситуации.
- Читать объявление переменной как с явной аннотацией типа, так и без неё.
- Формулировать, что такое вывод типов (type inference) и почему Kotlin не всегда требует писать тип вручную.
- Читать и строить цепочку `listOf(...).map { ... }.sum()`, объясняя, что делает каждое звено.
- Использовать в лямбде как неявный параметр `it`, так и явно названный параметр со стрелкой `->`.
